# 🚀 Быстрый старт - Система пользователей

## 📖 Для пользователей

### 1️⃣ Регистрация нового аккаунта

1. Откройте `index.html` или `auth.html`
2. Нажмите "Регистрация" (если на странице авторизации)
3. Заполните форму:
   - **Имя пользователя**: минимум 3 символа
   - **Пароль**: минимум 6 символов
   - **Подтверждение пароля**: должно совпадать
4. Нажмите "Зарегистрироваться"

✅ **Готово!** Вы получаете:
- Уникальный ID (начиная с 1)
- Стартовый баланс 1000₽
- Автоматический вход в систему

### 2️⃣ Вход в существующий аккаунт

1. Откройте `auth.html`
2. Введите имя пользователя и пароль
3. Нажмите "Войти"

✅ **Готово!** Ваш баланс и профиль загружены

### 3️⃣ Игра в казино

После входа:
- Ваше имя и ID отображаются в правом верхнем углу
- Ваш баланс виден на всех страницах
- Выберите любую игру и начинайте играть
- Баланс автоматически синхронизируется

### 4️⃣ Выход из аккаунта

1. Нажмите кнопку "Выход" (🚪) в правом верхнем углу
2. Подтвердите выход

## 👨‍💼 Для администраторов

### 1️⃣ Доступ к админ-панели

1. Откройте `admin.html`
2. Перейдите на вкладку "👥 Пользователи"

### 2️⃣ Просмотр пользователей

На экране отобразится таблица со всеми пользователями:
- **ID** - уникальный номер
- **Имя пользователя** - логин
- **Баланс** - текущий баланс в рублях
- **Дата регистрации** - когда создан аккаунт
- **Последний вход** - когда последний раз входил
- **Статус вывода** - активен или заблокирован
- **Действия** - кнопка редактирования

### 3️⃣ Изменение баланса пользователя

1. Найдите нужного пользователя в таблице
2. Нажмите кнопку "✏️ Изменить"
3. В модальном окне измените баланс:
   - Увеличьте для пополнения
   - Уменьшите для списания
4. Нажмите "Сохранить"

✅ **Готово!** Баланс обновлен мгновенно

### 4️⃣ Блокировка вывода средств

1. Откройте редактирование пользователя
2. Установите флажок "Заблокировать вывод средств"
3. Нажмите "Сохранить"

✅ **Готово!** Пользователь не сможет выводить средства

### 5️⃣ Разблокировка вывода

1. Откройте редактирование пользователя
2. Снимите флажок "Заблокировать вывод средств"
3. Нажмите "Сохранить"

✅ **Готово!** Пользователь может выводить средства

### Удаление всех пользователей:

1. Откройте консоль браузера (F12)
2. Выполните:
```javascript
localStorage.removeItem('lucybliss_users');
localStorage.removeItem('lucybliss_current_user');
localStorage.removeItem('userBalance');
console.log('Все данные пользователей удалены');
```
3. Обновите страницу

## ❓ Частые вопросы

**Q: Где хранятся данные пользователей?**  
A: В localStorage браузера. Это временное решение для разработки.

**Q: Можно ли восстановить пароль?**  
A: Пока нет. Это функция для будущих версий.

**Q: Безопасно ли хранить пароли в localStorage?**  
A: НЕТ! Текущая реализация только для разработки. Для продакшена нужен backend и хеширование.

**Q: Как синхронизируются данные между вкладками?**  
A: Через localStorage events. При изменении баланса все вкладки получают обновление.

**Q: Можно ли удалить пользователя?**  
A: Пока нет UI для удаления. Можно удалить через консоль браузера.

**Q: Что делать, если забыл пароль?**  
A: Пока только удаление через консоль и повторная регистрация.

**Q: Можно ли изменить ID пользователя?**  
A: Нет, ID генерируется автоматически и не может быть изменен.

## 📞 Поддержка

Если что-то не работает:

1. **Проверьте консоль браузера** (F12)
   - Смотрите на ошибки красного цвета
   
2. **Проверьте localStorage**
   - F12 → Application → Local Storage
   - Должны быть ключи: `lucybliss_users`, `lucybliss_current_user`

3. **Очистите кеш браузера**
   - Ctrl + Shift + Delete
   - Выберите "Очистить кеш и файлы cookie"

4. **Проверьте, что все файлы на месте**
   - auth.html, auth.css, auth.js
   - admin.html (обновлен)
   - admin.js (обновлен)
   - Все игровые файлы
