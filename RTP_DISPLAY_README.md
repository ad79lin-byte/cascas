# 📊 Отображение RTP в казино

## ✅ Что реализовано

Добавлено отображение RTP (Return to Player) во всех местах казино:

### 1. 🎰 Главная страница (index.html)
- **RTP бейджи** в правом верхнем углу каждой карточки игры
- Автоматическое обновление значений из админ-панели
- Динамический цвет в зависимости от уровня RTP

### 2. 🎮 Внутри игр
- **RTP индикатор** в хедере каждой игры (рядом с названием)
- Цветовая индикация:
  - 🟢 **Зелёный** (96.5%+) - высокий RTP
  - 🔵 **Синий** (95-96.4%) - средний RTP
  - 🟣 **Розовый** (<95%) - низкий RTP

## 🔄 Синхронизация с админкой

### Как это работает:
1. Открываете **admin.html**
2. Меняете RTP для любого слота
3. Нажимаете **"💾 Сохранить"**
4. **Автоматически обновляется:**
   - RTP на главной странице
   - RTP внутри игры
   - Игровая механика (выплаты, вероятности)

### Пример использования:

#### Шаг 1: Изменяем RTP в админке
```
Sweet Bonanza
┌─────────────────────────┐
│ RTP: [====96.5%====]    │ ← Двигаем слайдер
│                         │
│ Низкий | Средний | ✓Высокий
└─────────────────────────┘
💾 Сохранить
```

#### Шаг 2: Проверяем на главной странице
```
Карточка игры:
┌──────────────┐
│ 🍬💜❤️       │
│   RTP: 96.5% │ ← Обновилось!
└──────────────┘
```

#### Шаг 3: Заходим в игру
```
Хедер игры:
← Sweet Bonanza [RTP: 96.5%] 💎 ← Тоже обновилось!
```

## 🔧 Технические детали

### Структура файлов:

```
slot/
├── admin.html          # Админ-панель
├── admin.js            # API для настроек
├── index.html          # Главная (с RTP бейджами)
├── script.js           # Обновление RTP на главной
├── game.html           # Sweet Bonanza (с RTP индикатором)
├── game.js             # Логика игры + RTP
├── olympus.html        # Gates of Olympus (с RTP)
├── olympus.js          # Логика + RTP
├── crash.html          # Crash (с RTP)
├── crash.js            # Логика + RTP
├── nvuti.html          # Nvuti (с RTP)
└── nvuti.js            # Логика + RTP
```

### Подключение скриптов:

Во всех HTML файлах:
```html
<script src="admin.js"></script>  <!-- Первым! -->
<script src="game.js"></script>
```

### JavaScript API:

```javascript
// Получить настройки слота
const config = window.getSlotConfig('candy-slot');
console.log(config.rtp); // 96.5

// Получить глобальные настройки
const global = window.getGlobalConfig();
console.log(global.rtp); // 96.0

// Обновить RTP индикатор
updateRTPIndicator();
```

## 🎨 Кастомизация

### Изменить цвета RTP:

Откройте соответствующий CSS файл (`game.css`, `olympus.css`, и т.д.):

```css
.rtp-indicator {
    /* Ваш градиент */
    background: linear-gradient(135deg, #YOUR_COLOR1, #YOUR_COLOR2);
}
```

### Изменить позицию на главной:

В `style.css`:
```css
.rtp-badge {
    top: 8px;    /* Изменить верхний отступ */
    right: 8px;  /* Изменить правый отступ */
}
```

## ⚠️ Важные замечания

1. **localStorage** - настройки хранятся в браузере
2. **Обновление страницы** - RTP применяется при перезагрузке игры
3. **Разные браузеры** - настройки не синхронизируются между браузерами
4. **Продакшн** - для продакшна нужна база данных вместо localStorage
