## 🎯 Использование

### Регистрация нового пользователя

1. Откройте `auth.html`
2. Нажмите "Регистрация"
3. Введите имя пользователя (минимум 3 символа)
4. Введите пароль (минимум 6 символов)
5. Подтвердите пароль
6. Нажмите "Зарегистрироваться"

**Результат:**
- Создается новый пользователь с ID = (максимальный ID + 1)
- Начальный баланс: 1000₽
- Автоматический вход в систему
- Переход на главную страницу казино

### Вход в систему

1. Откройте `auth.html` (или перейдите на главную без авторизации)
2. Введите имя пользователя
3. Введите пароль
4. Нажмите "Войти"

**Результат:**
- Проверка учетных данных
- Обновление времени последнего входа
- Загрузка баланса пользователя
- Переход на главную страницу

### Управление пользователями (Админ-панель)

1. Откройте `admin.html`
2. Перейдите на вкладку "Пользователи" (👥)
3. Список всех пользователей отобразится в таблице

**Редактирование пользователя:**
1. Нажмите "✏️ Изменить" у нужного пользователя
2. Откроется модальное окно с данными
3. Измените баланс (можно увеличить или уменьшить)
4. Установите/снимите флажок "Заблокировать вывод средств"
5. Нажмите "Сохранить"

**Важно:**
- ID и имя пользователя нельзя изменить (защита от ошибок)
- Изменения применяются мгновенно
- Если пользователь сейчас в игре, его баланс обновится

## 🎮 Интеграция с играми

Все игры теперь работают с системой пользователей:

### При запуске игры:
1. Проверяется авторизация (`checkAuth()`)
2. Если не авторизован - редирект на `auth.html`
3. Загружается баланс из аккаунта пользователя
4. Отображается профиль (аватар, имя, ID)

### При изменении баланса:
1. Вызывается `saveUserBalance(newBalance)`
2. Обновляется текущий пользователь
3. Обновляется база всех пользователей
4. Синхронизация между вкладками (через localStorage)

### При возврате на главную:
1. Баланс синхронизируется с аккаунтом
2. Отображается актуальный баланс
3. Можно продолжить играть или выйти

## 🐛 Известные ограничения

1. **Нет хеширования паролей** - см. раздел Безопасность
2. **Один пользователь на устройство** - logout не очищает localStorage полностью
3. **Нет восстановления пароля** - нужно добавить email/SMS
4. **Нет ролей** - все пользователи равны, админ = отдельный доступ
5. **Нет истории транзакций** - только текущий баланс
