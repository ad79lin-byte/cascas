# 🎰 Админ-панель LucyBliss Casino

## 📋 Описание

Полноценная админ-панель для управления слотами казино с настройками RTP (Return to Player) и волатильности.

## 🚀 Как открыть админ-панель

### Способ 1: Через главное меню
1. Откройте главную страницу казино (`index.html`)
2. В левом боковом меню найдите раздел **"МЕНЮ"**
3. Нажмите на **"⚙️ Админ-панель"**

### Способ 2: Прямая ссылка
Откройте файл `admin.html` напрямую в браузере

## ⚙️ Основные функции

### 1. 🌐 Глобальные настройки

**Глобальный RTP** - влияет на все слоты казино
- Диапазон: 70% - 99%
- Рекомендуемое значение: 94-96%
- Применяется как базовый множитель для всех игр

### 2. 🎰 Управление отдельными слотами

Для каждого слота доступны следующие настройки:

#### 💰 RTP (Return to Player)
- **Что это:** Процент возврата денег игрокам от общей суммы ставок
- **Диапазон:** 85% - 98%
- **Пресеты:**
  - Низкий: 92% - больше прибыли для казино
  - Средний: 96% - стандартное значение
  - Высокий: 96.5%+ - выгоднее для игроков

#### 📈 Волатильность
Определяет частоту и размер выигрышей:

- **Низкая** - частые малые выигрыши
  - Игрок выигрывает чаще, но меньше
  - Стабильная игра, низкий риск
  
- **Средняя** - сбалансированная игра
  - Умеренная частота выигрышей
  - Баланс между риском и выигрышем
  
- **Высокая** - редкие крупные выигрыши
  - Большие паузы между выигрышами
  - Высокий риск, большие выплаты
  
- **Экстремальная** - очень редкие огромные выигрыши
  - Максимальный риск и потенциал
  - Для азартных игроков

#### 🎁 Частота бонусов
- **Диапазон:** 50-500 спинов
- **Значение:** "1 из X спинов"
- **Пример:** 150 = бонус выпадает примерно раз в 150 спинов

#### 💎 Максимальный множитель
Максимально возможный выигрыш за один спин/раунд
- **Sweet Bonanza:** до 21,000x
- **Gates of Olympus:** до 5,000x
- **Lucy Crash:** до 1,000x
- **Lucy Nvuti:** до 100x

### 3. 🎮 Специфичные настройки игр

#### Для Crash:
- **Средний краш-поинт** (1.5x - 3.0x)
  - Определяет средний множитель, при котором произойдёт краш
  - Чем выше значение, тем дольше растёт множитель

#### Для Nvuti:
- **Шанс угадывания** (40% - 55%)
  - Вероятность правильного угадывания
  - Влияет на сложность игры

## 📊 Статистика

Раздел **"Статистика"** показывает:
- **Всего спинов** - количество совершённых ставок
- **Всего поставлено** - общая сумма ставок
- **Всего выиграно** - общая сумма выигрышей
- **Реальный RTP** - фактический процент возврата

## 🔧 Технические детали

### Хранение данных
Все настройки сохраняются в `localStorage` браузера:
- **Ключ:** `slotsConfig`
- **Формат:** JSON

### Структура конфигурации
```json
{
  "global": {
    "rtp": 96.0
  },
  "slots": {
    "candy-slot": {
      "name": "Sweet Bonanza",
      "rtp": 96.5,
      "volatility": "high",
      "bonusFrequency": 150,
      "maxMultiplier": 21000
    }
  }
}
```

### API для игровых файлов

Игровые файлы могут получить настройки через:

```javascript
// Получить настройки конкретного слота
const config = window.getSlotConfig('candy-slot');

// Получить глобальные настройки
const global = window.getGlobalConfig();
```
